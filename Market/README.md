# Market package

This directory contains the Market-related classes for the Economic Simulator:

- Market.java — matching engine handling buy/sell orders and ticks
- Order.java — order representation
- Product.java — simple product holder
- ProductType.java — enum with many product types

I added these files under the Market/ package. If you want additional features (tests, examples, integration with your Economic_Entity classes, or to place files under src/...), tell me how you'd like them organized and I will add more.
